### Project Description
I built a Malayalam Dialogue Machine, a fun web application that turns my keyboard into a collection of iconic Malayalam movie dialogues. When I press a key, the corresponding dialogue plays, with some keys randomly choosing between multiple dialogues.

### The Problem (that doesn't exist)
often find myself in situations where I desperately need to play a Malayalam movie dialogue by pressing a random keyboard key. Unfortunately, keyboards normally just type letters instead of dramatically responding with movie dialogues. Clearly, this is a serious problem that needed solving.

### The Solution (that nobody asked for)
I solved this completely unnecessary problem by building a React-based Malayalam Dialogue Machine. I assigned movie dialogues to different keyboard keys and added a visual keyboard where keys containing audio are marked with dots. I also designed the interface with a comic-inspired style to make pressing random keys unnecessarily entertaining.

### Project Documentation
Working Principle
I open the Malayalam Dialogue Machine in my browser.
I see a virtual keyboard containing different keys.
Keys with available dialogues are marked with a pink dot.
I can either click a key on the virtual keyboard or press the corresponding key on my physical keyboard.
The assigned Malayalam movie dialogue starts playing.
For keys with multiple dialogues, the application randomly selects one.
The currently playing dialogue is displayed in the Now Playing section.
I can control the volume or stop the dialogue using the controls provided.

In short: I press a key → the website plays a Malayalam movie dialogue → absolutely nothing productive happens. 🎬😂
